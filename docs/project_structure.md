# Project Structure
## app/

主要 FastAPI 程式。

- api/
    API Router

- core/
    Config、Database、Security

- models/
    SQLAlchemy Models

- schemas/
    Pydantic Schemas

- templates/
    HTML

- static/
    CSS、JavaScript

## scripts/

自己維護用工具

例如：

- bulk_insert.py
- clear_database.py

## tests/

pytest 測試

## docs/

專案文件
